## Retaking them

1. Use a separate database with fictional data, never a real account.
2. Use a 1440 × 900 window at 100% zoom, and capture only the page.
3. Check each image for real names, email addresses, tokens and keys before committing it.
4. Keep the filenames, so the links in the README stay valid.
